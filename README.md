# Vocaby

給中文使用者的英文單字 iOS App。不只背單字，還會告訴你這個字怎麼把一句話說得更道地：先學字、再看它怎麼升級你的表達、接著練習，最後在對的時間再遇見它。

## 功能特色

### 📅 每天一點點

- **每日目標**：每天要學幾個字由你決定，10 到 100 個都可以
- **今天的待辦一眼看懂**：首頁就看得到今天的進度、要複習的字與連續學習天數
- **每日提醒**：設定提醒時間，時間到通知你回來學

### 🃏 雙面學習卡

- 正面是英文與音標，點一下翻到背面看中文意思、例句與翻譯
- 往三個方向滑動就能標記「認識」「不認識」或「收藏」
- 可以自動播放發音，邊看邊聽

### 🔁 在快忘記之前再複習

依照每個字的記憶程度安排下一次複習的時間（SM-2 間隔複習），記得牢的字久久出現一次，常忘的字會更常回來。

### ✏️ 多種練習方式

- 五種題型：表達選擇、詞義選擇、聽力選擇、拼字，或全部混合
- 題數與每題作答時間都可以調整
- 答錯的題目可以馬上再練一次

### 📈 看得見的進步

- **學習趨勢**：近 7 天與近 30 天的每日學習量
- **15 週熱度圖**：哪幾天有學、哪幾天偷懶，一張圖看完
- **學習狀態**：有多少字還沒開始、學習中或已掌握
- **成就徽章**：達成連續學習等里程碑時解鎖徽章，還有慶祝動畫

### 📚 內建 18,000 多個單字

收錄超過 18,000 個經過審核的單字，分成基礎、中階、進階三個程度，每個字都有音標、中英文解釋與例句。全部內建在 App 裡，不需要網路也能學。

### 📱 桌面小工具

在主畫面放上小工具，不用打開 App 就看得到今天的學習進度，以及正在學的表達升級。
